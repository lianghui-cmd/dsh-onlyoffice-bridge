feat: add typesetting, structure, and version tools (v0.5.0)

Adds 7 agent tools plus matching HTTP routes, bringing the total to 29.

Typesetting (docx / pptx):
- toc-regen: marks the existing TOC field dirty and clears its cached
  entries so the editor recomputes them, or inserts a TOC field at the
  body start when the document has none. For pptx it refreshes slide
  number placeholders and "第 X 页" style text instead.
- header-footer-set: writes header/footer parts per section, supports
  fixed text, version string, automatic PAGE field, and a distinct
  first page. Existing default references are replaced, not duplicated.

Structure:
- merge-doc: concatenates docx bodies while carrying sections, and
  renumbers/copies relationships so images survive; merges pptx by
  importing each slide's layout/master/theme closure.
- split-doc: splits docx by section break (falls back to halving
  paragraphs when there is only one section), or pptx by slide.

Version:
- snapshot / snapshot-list / restore-snapshot: immutable copies under
  snapshots/<fileKey>/, index kept in snapshots/index.json. Restore
  backs up the current version first and returns backupSnapId, so no
  content can be lost.

Implementation notes:
- lib/ooxml.js does part-level edits (rels, content types, part naming)
  instead of rebuilding document trees, which keeps original styles.
- Broken or non-OOXML files now produce a readable "不是有效的 Office
  文档" error rather than a raw jszip stack trace.
- Slide splitting also removes the notes pages of dropped slides; they
  referenced deleted parts and made PowerPoint prompt for repair.
- purge and TTL cleanup now remove the document's snapshot directory,
  so no orphan snapshots accumulate.

Tests: 44 node:test cases (8 new for version/param validation) plus the
10-case patch matrix; verified against real docx/pptx files where every
output was checked for dangling relationships.
